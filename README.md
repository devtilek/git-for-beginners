# Git for Beginners 🚀

Простое руководство по основам Git для начинающих.

## Что такое Git?

**Git** — это система контроля версий, которая помогает отслеживать изменения в коде и сохранять историю проекта.

**GitHub** — это платформа для хранения репозиториев и совместной работы над проектами.

## Основные команды Git

```bash
git init
```
Создать локальный репозиторий.

```bash
git status
```
Посмотреть состояние файлов.

```bash
git add .
```
Добавить изменения для коммита.

```bash
git commit -m "first commit"
```
Сохранить изменения в истории проекта.

```bash
git log
```
Посмотреть историю коммитов.

```bash
git push
```
Отправить изменения на GitHub.

```bash
git pull
```
Получить последние изменения из удалённого репозитория.

```bash
git clone <repository-url>
```
Скопировать репозиторий на компьютер.

## Основной рабочий процесс

```bash
git add .
git commit -m "описание изменений"
git push
```
